NVA VISUALS — PHOTO CHECKLIST
=============================

Drop your photos into THIS folder, named exactly as shown below
(all lowercase, .jpg). The site is already wired to look for these
names — you don't touch any code.

If a file is missing, that slot just shows a neutral placeholder,
so you can add photos one at a time and the site never looks broken.

-----------------------------------------------------------------
FILENAME          WHERE IT SHOWS                 SUGGESTED SHOT
-----------------------------------------------------------------
hero-1.jpg        Top of page, large frame       Best exterior / curb appeal
hero-2.jpg        Top of page, medium frame      Bright interior (living/kitchen)
hero-3.jpg        Top of page, small frame       A detail (fixture, texture, view)

gallery-1.jpg     Work section, big feature      Strongest overall shot
gallery-2.jpg     Work section                   Kitchen
gallery-3.jpg     Work section                   Twilight / dusk exterior
gallery-4.jpg     Work section                   Living room
gallery-5.jpg     Work section                   Backyard / pool / outdoor
gallery-6.jpg     Work section                   Detail or bathroom

about-1.jpg       About section, tall image      A clean, striking signature shot
-----------------------------------------------------------------

SIZING (do this before you drop them in — important):
  - Resize to about 2000-2400px on the LONGEST edge.
  - Save as JPEG (or WebP) at ~200-500 KB each.
  - Free tools: squoosh.app  or  tinypng.com  (drag photo in, download smaller).
  Oversized photos make the site slow and hurt Google ranking.

OPTIONAL — use WebP instead of JPEG for smaller files:
  If you save as .webp, rename the files the same way but with .webp,
  then open index.html, find "images/hero-1.jpg" etc. and change .jpg to .webp.
  (Or just stick with .jpg — totally fine.)

CAPTIONS:
  The little labels on the gallery (e.g. "Goodyear - Kitchen") are just
  examples. To change them, open index.html and edit the text inside the
  <span class="tag"> ... </span> lines. Optional.
